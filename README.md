# Portfolio

A modern personal portfolio website built with Vite and Preact to showcase projects, skills, experience, and contact information in a clean and responsive interface.

## Overview

This portfolio is designed to present:
- Personal branding and profile information
- A summary of technical skills
- Work experience and background
- Contact details and professional links

It is optimized for readability, mobile responsiveness, and fast loading.

## Tech Stack

- Vite
- Preact
- TypeScript
- CSS
- Vitest
